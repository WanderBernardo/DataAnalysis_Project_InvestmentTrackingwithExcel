# Investment Tracking with Excel
An investment simulator for real estate investment funds (REITs), featuring monthly contributions, a duration in years, and a monthly rate of return.


## Functions used:

1. *FV* (VF Portuguese) - It is used to calculate the future value of an investment based on a constant interest rate, taking into account periodic payments and/or a present value (initial amount).
2. *VLOOKUP* (PROCV Portuguese) - it is used to search for a value in the first column of a table and return a corresponding piece of data from another column in the same row.
